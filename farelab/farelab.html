Public Transport Tool

FareLab

A web platform for public transport fare calculation, cost transparency and scenario analysis.

In active development

About the project

FareLab is being developed to make public transport fare calculation more transparent, interactive and easier to understand.

The project combines my professional experience in public transport planning with programming foundations developed through CS50.

Current features

  • Fare calculation based on operational and financial inputs
  • Cost breakdown by fixed, variable and general components
  • Scenario creation and comparison
  • Inputs for fuel, labor, fleet, depreciation and subsidies

Goal

The goal is not only to calculate fares, but to make the logic behind them visible for planners, public managers and decision-makers.
